> *“O‘z yo‘lingni top. Kelajagingni yarat.”*

Foydalanuvchi uchun to'liq imkoniyatlar paneli:

4. 🤖 **AI Mentor** — Doimiy faol aqlli suhbatdosh:
   - 🍰 *Oddiy hayotiy misol rejimi* (Masalan: tort pishirish, oshxona, maktab)
   - 🔬 *Batafsil professional rejim*
   - *"Hali ham tushunmadim"* tugmasi orqali soddalashtirish.
5. 💻 **Code Lab (AI Amaliy Kod Laboratoriyasi)**:
   - 🐍 Python, 💻 C++, ☕ Java, 🌐 JavaScript, 🎨 HTML/CSS tillari.
   - ▶ **Ishga tushirish (Run)** va jonli terminal chiqishi.
   - 🤖 **AI Yordamchi**: Xatolik yuz berganda qaysi qatorda nima xatoligini, qanday to'g'irlashni va hayotiy misol bilan tushuntiradi!
   - 🧑‍💻 **Bosqichma-bosqich Topshiriq**: C++ da Kalkulyator yaratish (1-bosqich: ikkita son, 2-bosqich: `+`, 3-bosqich: `-, *, /`, 4-bosqich: tekshirish).
   - 🏆 **AI Code Review**: Sintaksis, Kod tuzilishi, Tavsiya, O'rganish kerak bo'lgan mavzu.
6. 🏗️ **Amaliy loyihalar** — Boshlang'ich (Kalkulyator, Portfolio), O'rta (Telegram AI bot, Online do'kon), Yuqori (AI tibbiy tashxis) loyihalar.

9. 🎯 **AI Maqsad Rejalashtiruvchisi** — Maqsad va bo'sh vaqtga qarab Kunlik tartib, Haftalik marralar va 6 oylik to'liq jadval.

14. 💬 **Savol-Javob Tizimi (Q&A)** — Har qanday mavzuni 3 xil chuqurlikda tushunish: Oddiy (misol) → O'rta → Batafsil.
